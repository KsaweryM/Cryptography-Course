# Task 3: factor it

Each number in `factor.py` is a product of two primes, as in RSA. Fill in the `TODO`: find the smallest factor
by trying divisors one by one. The program prints the factors and the time for each number.

Before you run it, predict: the numbers grow by 8 bits each. How much longer does each one take?
The last number takes several seconds.

## Run

```
python3 factor.py
```

Python 3, no extra libraries.
