# Task 3: find a

Each line in `dlog.py` gives a prime p, g and the public value A = g^a mod p. Fill in the `TODO`: find the secret a
by trying a = 1, 2, 3, ... The program prints a and the time.

Before you run it, predict: each p is 4 bits longer. How much longer will it take? The last one takes several seconds.

## Run

```
python3 dlog.py
```

Python 3, no extra libraries.
